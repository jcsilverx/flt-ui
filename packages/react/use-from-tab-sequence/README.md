# `@flt-ui/react-use-from-tab-sequence`

## Installation

To install `@flt-ui/react-use-from-tab-sequence`, run the following command:

```sh
# Using npm
$ npm install @flt-ui/react-use-from-tab-sequence

# or using pnpm
$ pnpm add @flt-ui/react-use-from-tab-sequence
```
