To install `@flt-ui/react-use-iso-morphic-effect`, run the following command:

```sh
# Using npm
$ npm install @flt-ui/react-use-iso-morphic-effect

# or using pnpm
$ pnpm add @flt-ui/react-use-iso-morphic-effect
```
