# `@flt-ui/react-use-mutation-observer`

## Installation

To install `@flt-ui/react-use-mutation-observer`, run the following command:

```sh
# Using npm
$ npm install @flt-ui/react-use-mutation-observer

# or using pnpm
$ pnpm add @flt-ui/react-use-mutation-observer
```
