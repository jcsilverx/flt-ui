# `@flt-ui/react-use-interact-outside`

## Installation

To install `@flt-ui/react-use-interact-outside`, run the following command:

```sh
# Using npm
$ npm install @flt-ui/react-use-interact-outside

# or using pnpm
$ pnpm add @flt-ui/react-use-interact-outside
```
