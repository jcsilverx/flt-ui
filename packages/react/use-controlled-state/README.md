# `@flt-ui/react-use-controllable-state`

## Installation

To install `@flt-ui/react-use-controllable-state`, run the following command:

```sh
# Using npm
$ npm install @flt-ui/react-use-controllable-state

# or using pnpm
$ pnpm add @flt-ui/react-use-controllable-state
```
