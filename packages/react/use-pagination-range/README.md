# `@flt-ui/react-use-pagination-range`

## Installation

To install `@flt-ui/react-use-pagination-range`, run the following command:

```sh
# Using npm
$ npm install @flt-ui/react-use-pagination-range

# or using pnpm
$ pnpm add @flt-ui/react-use-pagination-range
```
