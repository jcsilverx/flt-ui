<h1 align="center">flt/ui</h1>

<p align="center">
  A collection of unstyled, fully accessible UI components designed for building applications.
</p>

> ⚠️ This project is under development.

## Installation

First, enable [pnpm](<(https://pnpm.io/)>) if isn't enabled on your system. Open your terminal and run:

```sh
corepack enable pnpm
```

Then, install the dependencies:

```sh
pnpm install
```
